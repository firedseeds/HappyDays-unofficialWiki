# 关于国家

`/n new [国家名]` 建立新的国家 （你得先在**城镇银行**中存1000...吧）

`/n deposit [金额]` 向**你国家**的银行存钱

`/n leave` 离开你的国家**（希望你永远不会使用）**

### 国王指令

`/n set name [国家名]` 更改国家名**（免费）**

`/n withdraw [金额]` 向你国家的银行取钱
